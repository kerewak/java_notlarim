Java bize bir programlama dili aynı zamanda bir platform sunuyor.
Java insana yakın, yüksek seviyeli bir programlama dili, gürbüz, güvenli, nesne tabanlı bir programlama dilidir.
Platform: herhangi bir programın çalıştığı donanım veya yazılım ortamı.

class Basit{
  public static void main(String args[]){
  System.out.println("Merhaba Java");
  }
}

4 tane temel programlama paradigmamız var:
imperatif buyurgan, nesne tabanlı, fonksiyonel, mantıksal.


Java uygulama tipleri:
Standalone Application, Web Application, Enterprise Application, Mobile Application.


Java'nın 4 platformu veya sürümü vardır:
Java SE, Java EE, Java ME, JavaFx.
